## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/ManishKumar8292/Manish-Portfolio.git
```

Navigate to the project folder:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
